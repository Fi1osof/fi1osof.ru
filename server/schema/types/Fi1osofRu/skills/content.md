## Общая структура данных сайта fi1osof.ru

Сайт fi1osof.ru создавался не только для того, чтобы иметь общую справочную информацию о Николае Ланце, но и чтобы в любой момент можно было узнать:

- Чем он занимается, то есть какие области интересов у него сейчас. Потому что именно через призму текущих задач и можно понять что ему интересно
- Насколько он занят и принимает ли заказы и какие заказы. Спектр его знаний очень широкий, но это не означает, что он готов браться за любую работу, и цена - совсем не главный критерий оценки как в одну, так и в другую сторону. Главное для него - чтобы задача была интересная, и можно было узнать много всего нового. Но и стоимость конечно же играет роль, ибо его знания не стоят дешево.

## Полезные запросы и скилы

Чтобы собрать нужную информацию, изучи скилы про Задачи и Проекты, а так же используй запрос для получения последних записей активности.

```graphql
query timers {
  timers(orderBy: { createdAt: desc }, take: 50) {
    id
    startedAt
    stoppedAt
    Task {
      id
      title
      content
      projectId
      WorkLogs {
        id
        content
      }
    }
  }
}
```
